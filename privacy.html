隐私政策

最后更新：2026年8月17日

本政策说明本支持网站及当前儿童游戏产品方向的数据处理原则。

1. 网站用途

本站用于向家长和监护人提供游戏介绍、技术支持、购买恢复说明和隐私信息。

无儿童账号当前产品方向不要求儿童注册或登录。
不做广告画像当前产品方向不使用第三方广告。
数据最小化能在设备本地完成的功能优先在本地完成。

2. 本网站主动收集的信息

当前网站没有注册、登录、评论、聊天、联系表单、广告或我们自行部署的访问统计。

3. 支持邮件

如果你主动发送邮件至支持邮箱，我们会收到你主动提供的邮箱地址、正文和附件，并用于处理相关支持或隐私请求。

animalgames.kids@outlook.com

4. GitHub Pages 托管

本站目前使用 GitHub Pages 托管。

查看 GitHub 隐私声明 ↗

5. 儿童游戏的数据原则

  • 无需儿童注册或登录。
  • 不建立儿童个人资料。
  • 不提供社交功能、好友系统、聊天、评论或儿童公开个人主页。
  • 不使用公开排行榜或排名系统让儿童与其他玩家比较。
  • 不获取与玩法无关的定位、通讯录或广告标识符。
  • 不为了统计而引入不必要的第三方 SDK。
  • 购买由 Apple 的 App Store / StoreKit 体系处理。

6. 第三方链接

本站可能链接至 Apple App Store、Apple 支持或 GitHub 隐私页面。

7. 联系与删除请求

如需查询、纠正或删除通过支持邮件主动提供的信息，请联系支持邮箱。

animalgames.kids@outlook.com

8. 政策更新

如果托管方式、支持流程或数据处理发生变化，我们会更新本政策。
